⚠️ **ScarTissue Warning**: This PR reintroduces the bug fixed in commit ca7790f8951abce1296f69cd29e63cec5af50b1d. The proposed change to use `add_handler()` within the `merge()` method will cause cross-contamination between `handlers` and `inheritable_handlers` lists, because `add_handler()` with `inherit=True` incorrectly adds handlers to both lists simultaneously, breaking the critical invariant that these two handler collections must remain distinct.
