⚠️ **ScarTissue Warning**: This PR reintroduces a bug previously fixed in commit e99ccbc126d29aff40269024b2bebb8bab68715e. The removal of URL-encoding for the bgColor parameter in mermaid API calls will cause 400 errors from mermaid.ink when special characters like '!' are present in color values (e.g., '!white'). The original fix explicitly added `urllib.parse.quote` to properly encode these parameters before sending them to the external API.
