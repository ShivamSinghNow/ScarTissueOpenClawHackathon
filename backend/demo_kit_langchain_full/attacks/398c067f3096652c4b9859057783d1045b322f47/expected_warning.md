⚠️ **ScarTissue Warning**: This PR reintroduces a bug fixed in commit 398c067f3096652c4b9859057783d1045b322f47. The proposed changes will break default argument handling for tools with `args_schema` - when callers omit optional parameters that have Pydantic `Field(default=...)` values, those defaults will be discarded instead of passed to the tool function. This causes tools to receive incomplete arguments and throw `TypeError` for missing required positional arguments, even though the schema defines valid defaults. The original fix ensured that fields with non-None defaults from the Pydantic schema are included in the parsed input alongside explicitly provided values.
