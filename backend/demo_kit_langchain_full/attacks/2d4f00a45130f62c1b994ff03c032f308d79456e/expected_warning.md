⚠️ **ScarTissue Warning**: This PR reintroduces a bug fixed in commit 2d4f00a45130f62c1b994ff03c032f308d79456e. The original issue caused `OpenAIEmbeddings` to exceed OpenAI's 300,000 token per request limit when processing large document sets, resulting in 400 BadRequest errors (e.g., "Requested 673477 tokens, max 300000 tokens per request"). The fix implemented dynamic batching that respects the 300k token limit by tracking actual token counts and accumulating chunks until approaching the limit. This PR removes that safeguard by reverting to fixed-size batching based solely on `chunk_size`, which can create batches of 1000 chunks × 8191 tokens = 8,191,000 tokens, far exceeding the API limit and breaking large embedding workloads.
