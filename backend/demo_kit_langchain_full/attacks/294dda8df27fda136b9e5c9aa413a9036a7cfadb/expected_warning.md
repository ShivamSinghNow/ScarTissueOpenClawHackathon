⚠️ **ScarTissue Warning**: This PR reintroduces a bug previously fixed in commit 294dda8df27fda136b9e5c9aa413a9036a7cfadb. The removal of URL encoding for the `bgColor` parameter will cause HTTP 400 errors when using named colors (e.g., `white`, `black`) because these colors are prefixed with `!` which must be encoded as `%21` for the mermaid.ink API. The original fix added `urllib.parse.quote()` specifically to handle special characters in background color values, and removing this encoding breaks support for named color parameters.
